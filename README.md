# robur-dynamics
Official ROBUR Dynamics game development repository.

## Stav projektu

ROBUR Dynamics je připravovaný herní projekt. Herní engine zatím nebyl vybrán. V repozitáři je vývojová dokumentace. Hratelný prototyp ani instalační postup zatím nejsou k dispozici.

## Kde začít

- [Pravidla spolupráce](CONTRIBUTING.md) popisují práci s úkoly, větvemi a pull requesty.
- [Instrukce pro Codex](AGENTS.md) popisují, které podklady má Codex při práci použít.
- [Game design](docs/GAME_DESIGN.md) obsahuje osnovu návrhu hry a otevřené otázky.
- [Lore](docs/LORE.md) slouží k evidenci podkladů ke světu a jeho kánonu.
- [Roadmapa](docs/ROADMAP.md) navrhuje pořadí vývojových milníků.
- [Decision log](docs/DECISIONS.md) eviduje rozhodnutí a jejich odůvodnění.

Pro práci s dokumentací stačí lokální kopie repozitáře a editor Markdownu. V Codexu otevři kořen složky `robur-dynamics`, kde je soubor `AGENTS.md`. Před zahájením úkolu projdi pravidla spolupráce a založ vlastní větev.

Herní kód, assety a nastavení přibudou podle potřeb prototypu a zvoleného enginu. Diskuse může probíhat v chatu nebo v GitHub issue. Společně potvrzené závěry zachyťte v dokumentaci repozitáře.
