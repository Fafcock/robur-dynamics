# Roadmapa

Pořadí milníků je pracovní návrh bez termínů. Konkrétní úkoly a odpovědnosti veďte v GitHub issues nebo je uveďte v týmové dohodě.

| Milník | Kdy je hotový |
| --- | --- |
| Sdílený vývojový základ | Oba členové týmu mají přístup k repozitáři a prošli společnou dokumentaci v prvním PR. |
| Návrh prvního prototypu | Tým odsouhlasil, jaký zážitek chce ověřit, co si půjde vyzkoušet a podle čeho vyhodnotí výsledek. |
| Výběr enginu | Tým zapsal požadavky prototypu, porovnal vhodné možnosti a zaznamenal volbu s odůvodněním. |
| První hratelný prototyp | Oba členové týmu ho umí spustit podle README, vyzkoušet domluvenou interakci a zaznamenat výsledek. |

Po vyzkoušení prototypu domluvte další milník podle výsledku. Potvrzené změny směru zapište do [decision logu](DECISIONS.md).
