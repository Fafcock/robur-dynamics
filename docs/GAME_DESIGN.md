# Game design

Tento dokument je pracovní osnova pro návrh ROBUR Dynamics. Otevřené položky čekají na dohodu týmu. Konkrétní nápady lze zapisovat se stavem **Návrh**. Stav **Schváleno** použijte po společném potvrzení a přidejte odkaz na [decision log](DECISIONS.md).

| Oblast | Stav | Otázka k dohodě |
| --- | --- | --- |
| Vize hry | Otevřeno | Jaký zážitek má hra hráči nabídnout? |
| Žánr a cílová platforma | Otevřeno | Jaká forma hry a platforma dávají pro první verzi smysl? |
| Role a cíl hráče | Otevřeno | Koho nebo co hráč ovládá a čeho se snaží dosáhnout? |
| Herní smyčka | Otevřeno | Co hráč opakuje a jak pozná výsledek svých akcí? |
| Mechaniky a postup | Otevřeno | Kterou interakci má smysl ověřit jako první? |
| Vizuální a zvukový směr | Otevřeno | Jakou prezentaci potřebuje první prototyp? |
| Rozsah prototypu | Otevřeno | Co musí jít vyzkoušet, aby tým mohl návrh posoudit? |

U konkrétního návrhu zapište očekávaný hráčský zážitek, nejmenší způsob ověření a pozorování, podle kterého vyhodnotíte výsledek. Související náměty ke světu veďte v dokumentu [Lore](LORE.md).
